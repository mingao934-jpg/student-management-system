# Student Management System (Command Line)

A simple command-line Student Management System written in Python.

This is my first small Python project. It allows you to manage student information (name + scores) with basic CRUD operations and file saving/loading.

## Features

- Add a new student (with multiple scores)
- Display all students and their average scores
- Search for a student by name
- Delete a student
- Calculate the overall average score of all students
- Save data to a text file (`students.txt`)
- Load data from the text file
- Basic error handling (empty name, invalid scores, etc.)

## How to Run

1. Make sure you have **Python 3.10 or higher** installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python main.py
